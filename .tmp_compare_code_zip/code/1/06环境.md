# 强化学习环境系统设计与接口规范
## 环境
在综述中提到，强化学习训练流程离不开智能体与环境的持续交互，本文将详细介绍强化学习环境系统的功能及标准接口函数。

## 概述
强化学习环境是基于输入动作，输出观测、奖励等反馈的功能模块，用于表达强化学习算法所求解的问题场景。

开发框架通过场景适配模块，对仿真器进行封装，将其特化的接口、协议转换为强化学习环境统一的接口和协议，供智能体调用。

强化学习环境系统主要提供如下功能：
- 接收配置信息，用于指定自身初始化方式，如环境中各类元素的初始状态。
- 输出观测、奖励信息，支撑智能体的策略预测与模型训练。
- 输出观测、奖励之外的扩展信息，为强化学习系统相关组件提供支撑，实现可视化、运行日志、状态监测等功能。
- 接收动作指令，驱动环境完成状态转移，并生成新一轮观测与奖励。

## 环境使用
开发框架通过场景适配模块完成问题场景的标准化封装，向开发者提供统一的交互接口与通信协议。不同环境在观测空间、动作空间、奖励结构上存在差异，对应观测、奖励等数据结构需以对应环境的官方数据协议文档为准。

开发者可在训练工作流 workflow 中获取环境实例，通过标准接口完成智能体与环境的全流程交互。

## 核心函数介绍
### reset(usr_conf)
重置环境至配置文件指定的初始状态，并返回初始观测信息。
```python
# usr_conf为开发者传入的环境配置
obs, state = env.reset(usr_conf=usr_conf)
```

#### Parameters
| 参数名 | 类型 | 介绍 |
| ---- | ---- | ---- |
| usr_conf | dict | 环境配置文件 |

#### Returns
| 参数名 | 类型 | 介绍 |
| ---- | ---- | ---- |
| obs | dict | 环境观测信息 |
| state | dict | 环境全局信息 |

---

### step(act, stop_game = false)
执行智能体传入的动作指令，完成一次环境状态转移，返回新观测、奖励及终止状态等信息。
```python
frame_no, _obs, score, terminated, truncated, _state = env.step(act, stop_game=False)
```

#### Parameters
| 参数名 | 类型 | 介绍 |
| ---- | ---- | ---- |
| act | dict | 环境执行的动作指令 |
| stop_game | bool | 是否主动结束当前对局 |

#### Returns
| 参数名 | 类型 | 介绍 |
| ---- | ---- | ---- |
| frame_no | int | 当前环境实例运行帧号 |
| _obs | dict | 当前帧观测信息 |
| score | int | 当前帧奖励信息 |
| terminated | bool | 当前环境实例是否正常结束 |
| truncated | bool | 当前环境实例是否异常中断 |
| _state | dict | 当前帧全部环境状态信息 |
