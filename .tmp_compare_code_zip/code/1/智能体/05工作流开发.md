# 强化学习训练工作流开发文档
## 一、工作流概述
在智能体开发完成后，基于分布式计算框架实现**强化学习训练工作流**，核心目标是让智能体与环境持续交互、自动收集训练样本、迭代优化模型参数，最终完成智能体策略的迭代升级。

训练工作流通过框架提供的 `workflow` 核心函数实现，串联**环境交互、样本采集、模型训练、模型保存**全流程，支持单机训练与分布式训练两种模式。

## 二、核心函数定义
### 1. 主函数：workflow
训练工作流的入口函数，由框架挂载调用，负责统筹整个训练流程。

```python
@attached

```

#### 参数说明

| monitor | Monitor | 框架提供的训练监控组件，用于监控训练状态 |

## 三、完整训练工作流代码实现
```python
import time

# 核心训练工作流函数
@attached
def workflow(envs, agents, logger=None, monitor=None):
    """
    强化学习训练主工作流
    实现：环境交互 -> 样本收集 -> 模型迭代 -> 模型保存 全流程
    """
    # 1. 获取单个环境和智能体（单环境单智能体场景）
    env, agent = envs[0], agents[0]
    
    # 2. 训练超参数配置
    epoch_num = 1000  # 总训练轮数（epoch）
    episode_num_every_epoch = 1000  # 每个epoch包含的回合数（episode）
    last_save_model_time = time.time()  # 初始化模型保存时间戳

    # 3. 顶层训练循环：epoch 迭代
    for epoch in range(epoch_num):
        # 4. 执行多回合交互，生成训练样本
        # run_episodes 为生成器，逐回合返回处理后的样本数据
        for g_data in run_episodes(episode_num_every_epoch, env, agent, logger, monitor):
            # 5. 智能体模型训练
            # 单机训练：直接训练；分布式训练：样本发送至样本池
            agent.learn(g_data)
            # 清空样本，保证下一次采集全新数据
            g_data.clear()
        
        # 6. 定时保存模型（间隔 300 秒/5 分钟）
        now = time.time()
        if now - last_save_model_time >= 300:
            agent.save_model()
            last_save_model_time = now
            logger.info(f"模型已自动保存，当前 epoch: {epoch}")


def run_episodes(n_episode, env, agent, logger, monitor):
    """
    执行多回合（episode）环境交互，生成训练样本
    :param n_episode: 单次执行的回合总数
    :yield: 处理完成的回合样本，用于模型训练
    """
    for episode in range(n_episode):
        # 1. 回合初始化
        done = False  # 回合结束标志
        collector = []  # 样本采集器，存储单回合所有帧数据

        # 2. 重置环境，获取初始状态
        obs, state = env.reset(usr_conf=usr_conf)
        obs_data = agent.observation_process(obs, state)

        # 3. 加载最新模型（分布式场景必需，单机可选）
        agent.load_model(id="latest")

        # 4. 单回合内的帧循环交互
        while not done:
            # 4.1 智能体推理，预测下一步动作
            act_data = agent.predict(list_obs_data=[obs_data])[0]
            
            # 4.2 动作数据处理，适配环境协议
            act = agent.action_process(act_data)

            # 4.3 与环境交互，执行动作
            frame_no, _obs, score, terminated, truncated, _state = env.step(act)
            if _obs is None:
                break

            # 4.4 观测数据特征处理
            _obs_data = agent.observation_process(_obs, _state)

            # 4.5 容灾判断：异常截断直接退出
            if truncated and frame_no is None:
                break

            # 4.6 奖励函数计算
            reward = reward_shaping(obs_data, _obs_data, state, _state)
```

## 四、核心流程说明
### 1. 训练层级结构
训练流程采用**双层循环**设计：
- 外层：`epoch` 大循环，控制整体训练迭代次数
- 内层：`episode` 回合循环，每个 epoch 执行多次环境交互回合

### 2. 单回合交互核心步骤
1. **环境初始化**：重置环境，获取初始观测状态
2. **模型加载**：加载最新版本模型（分布式场景必需）
3. **智能体推理**：基于当前观测预测动作
4. **环境交互**：执行动作，获取下一状态、奖励、结束信号
5. **数据处理**：特征加工、奖励塑形、样本构造
6. **样本返回**：回合结束后，输出处理完成的训练样本

### 3. 模型训练与保存
- 训练：`agent.learn()` 接收样本完成参数更新，自动适配单机/分布式模式
- 保存：定时自动保存模型，防止训练中断丢失进度

### 4. 辅助功能
- **日志**：通过 `logger` 记录训练关键信息
- **监控**：`monitor` 组件监控训练状态
- **容灾**：异常场景判断，保证训练稳定性
- **样本管理**：自动清空历史样本，保证数据有效性
