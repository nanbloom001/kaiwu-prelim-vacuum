# 强化学习模型开发文档
## 1. 开发目录规范
智能体模型统一存放路径：
`<智能体名称>/model/model.py`

## 2. 模型核心定义
强化学习模型为**基于特征输入、输出策略的神经网络模型**，需严格遵循 PyTorch 规范，继承 `torch.nn.Module` 基类实现。

### 核心参数说明
| 参数名 | 类型 | 默认值 | 作用 |
|--------|------|--------|------|
| `state_shape` | int/tuple | - | 输入状态特征的维度/形状（模型输入尺寸） |
| `action_shape` | int | 0 | 输出动作空间的维度（模型输出尺寸） |
| `softmax` | bool | False | 控制是否对模型输出做Softmax归一化（强化学习策略输出常用） |

### 规范要求
1. 模型类必须命名为 `Model`，且严格继承 `torch.nn.Module`
2. 初始化函数必须保留 `super().__init__()` 调用父类构造方法
3. 输入为**环境状态特征**，输出为**动作策略**，符合强化学习模型逻辑

### 总结
1. 固定开发路径：`<智能体名称>/model/model.py`
2. 模型必须继承 `nn.Module`，类名固定为 `Model`
3. 初始化参数：`state_shape`（输入）、`action_shape`（输出）、`softmax`（策略归一化）
4. 核心逻辑：状态特征输入 → 神经网络 → 动作策略输出
