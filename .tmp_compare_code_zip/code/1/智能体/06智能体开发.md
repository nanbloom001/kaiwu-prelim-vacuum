# 强化学习智能体开发规范
## 一、开发目录
`<智能体名称>/agent.py`

## 二、核心功能概述
强化学习智能体负责**调用模型决策、与环境交互、通过算法更新模型参数**，是连接模型、算法与训练环境的核心组件，需实现指定核心函数以适配单机/分布式训练、模型评估等场景。

---

## 三、核心函数实现规范
### 1. learn 函数
**功能**：消费训练样本完成模型训练，单机/分布式训练用法不同
- 单机训练：手动调用执行一步训练
- 分布式训练：自动循环执行训练，需手动调用发送样本至样本池

```python
def learn(self, list_sample_data):
    """
    训练函数：调用算法消费训练样本更新模型参数
    Args:
        list_sample_data (list): 训练样本(SampleData)列表
    """
    self.algo.learn(list_sample_data)  # 调用算法执行训练
```

#### 参数说明
| 参数名 | 类型 | 介绍 |
|--------|------|------|
| list_sample_data | list | 训练样本(SampleData)列表 |

### 4. load_model 函数
**功能**：从模型池加载指定版本模型参数，Actor需手动调用

```python
@load_model_wrapper
def load_model(self, path=None, id="1"):
    """
    加载模型参数
    Args:
        path (str): 模型文件加载路径
        id (str): 模型参数文件索引ID
    """
    # 文件名需与save_model完全一致
    model_file_path = f"{path}/model.ckpt-{str(id)}.pkl"
    self.model.load_state_dict(
        torch.load(model_file_path, map_location=self.device),
    )
```

#### 参数说明
| 参数名 | 类型 | 介绍 |
|--------|------|------|
| path | string | 模型参数文件加载路径（框架自动传入） |
| id | string | 模型参数文件索引ID（指定加载版本） |

---

### 5. save_model 函数
**功能**：保存当前模型参数，框架自动打包为zip文件（本地/云端存储）

```python
@save_model_wrapper
def save_model(self, path, id):
    """
    保存模型参数（拷贝至CPU后存储）
    Args:
        path (str): 模型文件保存路径
        id (str): 模型文件索引ID
    """
    # 文件名必须包含 model.ckpt-id 字段
    model_file_path = f"{path}/model.ckpt-{str(id)}.pkl"
    
    # 模型参数拷贝至CPU后保存
    model_state_dict_cpu = {k: v.clone().cpu() for k, v in self.model.state_dict().items()}
    torch.save(model_state_dict_cpu, model_file_path)
```

#### 参数说明
| 参数名 | 类型 | 介绍 |
|--------|------|------|
| path | string | 模型文件保存路径（框架自动传入） |
| id | string | 模型文件索引ID（框架自动获取最新版本） |

## 四、关键注意事项
1. **文件名一致性**：`load_model` 和 `save_model` 的模型文件名必须完全匹配
2. **设备适配**：保存模型时需将参数拷贝至CPU，加载时自动映射到运行设备
3. **装饰器必须添加**：`predict/exploit/load_model/save_model` 需添加指定装饰器
4. **分布式适配**：分布式训练中`learn`无需手动调用训练逻辑，仅需手动发送样本
