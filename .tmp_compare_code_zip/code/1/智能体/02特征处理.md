## 二、定义数据结构
### 开发目录
`<智能体文件夹>/feature/definition.py`

### 核心说明
框架预定义 3 种基础数据类型，开发者通过 `create_cls` 动态自定义属性：
- `ObsData`：智能体预测输入（agent.predict() 使用）
- `ActData`：智能体预测输出（agent.predict() 使用）
- `SampleData`：训练样本数据（agent.learn() 使用）

### 核心函数：create_cls
动态创建数据结构类，属性名称/数量无限制。

#### 标准示例
```python
# 定义观测数据结构
ObsData = create_cls("ObsData", 
    feature=None, 
)

# 定义动作数据结构
ActData = create_cls("ActData",
    action=None,
    prob=None,
)

# 定义训练样本数据结构
SampleData = create_cls("SampleData",
    npdata=None
)
```

#### 参数说明
| 参数 | 类型 | 说明 |
|------|------|------|
| 第一个参数 | str | 类名称（固定为 ObsData/ActData/SampleData） |
| 其余参数 | 自定义 | 类属性，默认值为 None |

## 六、样本处理
### 开发目录
`<智能体文件夹>/feature/definition.py`

### 核心说明
将环境-智能体交互产生的**轨迹数据**，转换为 `SampleData` 训练样本；
分布式训练需支持 `SampleData ↔ numpy.array` 互转。

---

### 1. 核心函数：sample_process
```python
@attached
def sample_process(self, list_game_data):
    # 批量轨迹数据 → 训练样本列表
    return [SampleData(**i.__dict__) for i in list_game_data]
```

#### 参数说明
| 参数 | 类型 | 说明 |
|------|------|------|
| list_game_data | list(Frame) | 轨迹数据列表，批处理输入 |

#### 返回值
`list(SampleData)`：训练样本集合。

---

### 2. 分布式训练数据转换（必须实现）
为支持网络传输，需实现一对**互逆函数**，且必须添加 `@attached` 装饰器。

#### SampleData → Numpy.array
```python
@attached
def SampleData2NumpyData(g_data):
    # 样本数据转为 numpy 数组
    return g_data.npdata
```

#### Numpy.array → SampleData
```python
@attached
def NumpyData2SampleData(s_data):
    # numpy 数组转回样本数据
    return SampleData(npdata=s_data)
```

#### 参数&返回值
| 函数 | 输入 | 输出 |
|------|------|------|
| SampleData2NumpyData | SampleData | numpy.array |
| NumpyData2SampleData | numpy.array | SampleData |
