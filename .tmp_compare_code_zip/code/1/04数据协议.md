# 数据协议
为方便同学们调用原始数据和特征数据，提供以下协议供查阅。

## 一、环境返回数据协议
### observation（观测信息）
| 数据名 | 数据类型 | 数据描述 |
| ---- | ---- | ---- |
| step_no | int32 | 当前步数 |
| frame_state | FrameState | 帧状态数据 |
| env_info | EnvInfo | 环境信息 |
| map_info | list[list[int]] | 地图信息（21×21 视野网格，0=障碍物，1=已清扫，2=污渍） |
| legal_act | list[int] | 合法动作列表，长度为 8 |

---

### FrameState（帧状态）
| 数据名 | 数据类型 | 数据描述 |
| ---- | ---- | ---- |
| frame_no | int32 | 当前帧号 |
| heroes | HeroState | 小悟机器人状态 |
| npcs | list[NpcState] | 官方机器人状态列表 |
| organs | list[OrganState] | 物件状态列表（充电桩） |

---

### HeroState（小悟机器人状态）
| 数据名 | 数据类型 | 数据描述 |
| ---- | ---- | ---- |
| hero_id | string | 机器人实体 ID |
| pos | Position | 当前位置 {x, z} |
| battery | int32 | 当前电量 |
| battery_max | int32 | 电量上限（默认 200） |
| score | int32 | 当前得分（= 清扫地面数量） |
| dirt_cleaned | int32 | 已清扫污渍数量 |

---

### NpcState（官方机器人状态）
| 数据名 | 数据类型 | 数据描述 |
| ---- | ---- | ---- |
| npc_id | string | 机器人实体 ID |
| pos | Position | 当前位置 {x, z}（全局绝对坐标） |
| idx | int32 | 机器人索引（1-4） |

---

### OrganState（充电桩状态）
| 数据名 | 数据类型 | 数据描述 |
| ---- | ---- | ---- |
| sub_type | int32 | 物件类型：1 = 充电桩 |
| config_id | int32 | 配置 ID（充电桩索引） |
| pos | Position | 位置 {x, z} |
| w | int32 | 宽度（格子数，充电桩为 3） |
| h | int32 | 高度（格子数，充电桩为 3） |

---

### EnvInfo（环境信息）
| 数据名 | 数据类型 | 数据描述 |
| ---- | ---- | ---- |
| total_score | int32 | 总得分（= 清扫地面数量） |
| step_no | int32 | 当前步数 |
| clean_score | int32 | 清扫得分 |
| total_dirt | int32 | 污渍总数量 |
| battery_max | int32 | 电量上限 |
| remaining_charge | int32 | 当前剩余电量 |
| charge_count | int32 | 充电次数 |
| total_charger | int32 | 充电桩数量 |
| npc_count | int32 | 官方机器人数量 |
| pos | Position | 小悟机器人当前位置 |
| total_map | int32 | 总地图数 |
| map_random | int32 | 是否随机地图（0/1） |
| max_step | int32 | 最大步数 |
| finished_steps | int32 | 已完成步数 |
| step_cleaned_cells | list[Position] | 本步清扫的坐标列表 |

---

### Position（位置）
| 数据名 | 数据类型 | 数据描述 |
| ---- | ---- | ---- |
| x | int32 | X 坐标（栅格） |
| z | int32 | Z 坐标（栅格） |

---

## 二、动作空间协议
| 动作值 | 方向 | 向量 (dx, dy) | 说明 |
| ---- | ---- | ---- | ---- |
| 0 | 右 (→) | (1, 0) | 向右移动 1 格 |
| 1 | 右上 (↗) | (1, -1) | 向右上移动 1 格 |
| 2 | 上 (↑) | (0, -1) | 向上移动 1 格 |
| 3 | 左上 (↖) | (-1, -1) | 向左上移动 1 格 |
| 4 | 左 (←) | (-1, 0) | 向左移动 1 格 |
| 5 | 左下 (↙) | (-1, 1) | 向左下移动 1 格 |
| 6 | 下 (↓) | (0, 1) | 向下移动 1 格 |
| 7 | 右下 (↘) | (1, 1) | 向右下移动 1 格 |

---

## 三、方向枚举协议
```
        2(↑)
         |
   3(↖)  |  1(↗)
      \  |  /
       \ | /
4(←)----[P]----0(→)
       / | \
      /  |  \
   5(↙)  |  7(↘)
         |
        6(↓)
```

---

## 四、任务状态协议
| 状态值 | 说明 |
| ---- | ---- |
| running | 任务进行中 |
| completed | 任务正常完成（达到最大步数） |
| failed | 任务失败（电量耗尽/碰撞官方机器人），fail_reason 字段说明具体原因 |

---

## 五、视野网格值协议
| 值 | 含义 |
| ---- | ---- |
| 0 | 障碍物/地图边界（不可通行） |
| 1 | 可通行道路（已清扫） |
| 2 | 污渍地面（未清扫） |
