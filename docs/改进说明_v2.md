# 清扫机器人智能体改进说明 v2.0

## 主要改进点

### 1. 主动寻找充电桩（解决核心问题）

**问题**：上一版本机器人不会主动寻找充电桩，甚至一次都没有充电就结束了。

**改进措施**：
- **开局优先找桩**：初始阶段优先探索以发现更多充电桩（`need_safe_explore = len(self.charger_map) < 2 and step < 100`）
- **提前充电模式**：新增 `EARLY_CHARGE` 模式，允许在电量尚未耗尽时就充电
  - 触发条件：电量低于65%、已清扫至少15步、距离充电桩较近（≤8格）、当前区域清扫完成度较高
  - 这样可以让机器人在电量充足时回桩充电，而不是等到电量紧张

**关键参数**：
```python
EARLY_CHARGE_THRESHOLD = 0.65      # 电量低于65%时考虑提前充电
CHARGE_NEAR_DISTANCE = 8           # 距离充电桩8格以内时考虑充电
MIN_CLEAN_BEFORE_CHARGE = 15       # 至少清扫15步才考虑充电
```

### 2. 优化路径规划，减少重复覆盖

**问题**：上一版本路线重复度高，电量使用率不高。

**改进措施**：
- **访问计数惩罚**：A*路径规划时增加对重复访问的惩罚，鼓励探索新区域
  ```python
  move_cost += Config.REVISIT_PENALTY_BASE * min(visit_count_map[neighbor[1], neighbor[0]], 5)
  ```
- **条带清扫优化**：
  - 限制单条条带长度（80步），避免过长条带导致绕路
  - 换道时检查目标位置是否重复访问
  - 支持条带轴切换（横向/纵向），适应不同区域形状
- **动作选择优化**：选择动作时增加对访问次数的惩罚
  ```python
  score = -dist - 1.8 * danger - 0.08 * revisit + anchor_bonus
  ```

**关键参数**：
```python
REVISIT_PENALTY_BASE = 0.5         # 重复访问惩罚基数
STRIPE_MAX_LEN = 80                # 条带最大长度
```

### 3. 保持官方机器人避让能力

**改进措施**：
- 保留动态危险图（`robot_danger_map`）
- 保留轨迹预测（未来5步）
- 路径规划时避开高危险区域
- 紧急避让模式优先级最高

### 4. 电量管理优化

**改进措施**：
- **安全电量计算**：
  ```python
  safe_energy = min_return_cost + DETOUR_MARGIN + UNKNOWN_MARGIN + DOCK_BUFFER
  ```
- **降低冗余**：针对200电量优化，降低DETOUR_MARGIN和UNKNOWN_MARGIN，提高电量利用率
- **动作级可行性检查**：每个动作都检查执行后是否能安全返回充电桩

**关键参数**：
```python
DETOUR_MARGIN = 6                  # 降低绕障冗余
UNKNOWN_MARGIN = 4                 # 降低未知区域冗余
DOCK_BUFFER = 8                    # 增加到达缓冲
```

## 模式优先级

| 优先级 | 模式 | 触发条件 |
|--------|------|----------|
| P0 | EMERGENCY_EVADE | 预测2-3步内与官方机器人冲突 |
| P1 | RETURN_TO_CHARGER | 电量 ≤ 安全电量 |
| P2 | EARLY_CHARGE | 电量较低、靠近充电桩、区域完成度高【新增】 |
| P3 | STUCK_RECOVERY | 卡住检测 |
| P4 | CHARGER_TRANSFER | 换桩 |
| P5 | STRIPE_CLEANING | 条带清扫（主模式） |
| P6 | DIRECT_DIRT_PICKUP | 直接清扫视野内脏点 |
| P7 | SAFE_EXPLORATION | 安全探索 |

## 测试建议

1. **观察充电行为**：检查机器人是否会在电量适中时（如60-70%）主动返回充电桩
2. **观察路径覆盖**：检查清扫轨迹是否更加规整，重复覆盖是否减少
3. **观察避障**：确保机器人能有效避开官方机器人
4. **监控指标**：
   - 充电次数（应增加）
   - 重复覆盖率（应降低）
   - 单位电量清扫效率（应提高）

## 可能的调参方向

如果提前充电过于保守或激进，可以调整：
- `EARLY_CHARGE_THRESHOLD`: 提高（如0.7）让机器人更早充电，降低（如0.5）让机器人更晚充电
- `CHARGE_NEAR_DISTANCE`: 调整触发提前充电的距离阈值
- `REVISIT_PENALTY_BASE`: 调整重复访问惩罚力度
