## 1. 目标与成功标准

### 1.1 总目标
在腾讯开悟“清扫大作战”任务中，构建可训练、可泛化的 PPO 智能体，稳定提升清扫得分并降低失败率。

### 1.2 阶段性成功标准
- 阶段一（P0）通过：`python train_test.py` 稳定运行，无维度/动作配置错误，reward 非零可学习。
- 阶段二（P1）通过：单地图平均得分持续上升，电量耗尽率与碰撞率明显下降。
- 阶段三（P2）通过：多地图训练后方差下降，泛化得分提升。
- 冲刺阶段（P3）通过：达到竞赛目标区间（建议目标：平均得分 > 400，成功率 > 80%）。

## 4. 分阶段执行计划

## Phase 1：基础修复（P0，3-5天）

### 目标
打通“可学习”最小闭环：正确动作维度 + 有效特征 + 有效奖励。

### 任务清单
1. 修正配置：
- `ACTION_NUM: 2 -> 8`
- `DIM_OF_OBSERVATION: 1 -> 470`（按方案02特征设计）
2. 实现特征提取（470维）：
- 地图视野 `21x21=441`（归一化）
- 电量比例、步数比例、位置、清扫进度
- 充电桩距离、NPC距离+方向
- 上一步动作 one-hot
3. 实现奖励函数：
- 清扫主奖励（+1/格）
- 时间惩罚（-0.01/步）
- 低电量充电引导
- NPC近距离惩罚
- 终局惩罚（碰撞/耗电）
4. 运行冒烟：
- `cd code && python train_test.py`
- 检查训练日志是否出现非零 reward、loss 合理变化。

### 交付物
- 可运行 PPO 训练链路
- 第一版特征与奖励实现
- 一次完整训练日志（含关键指标截图或文本记录）

### 验收标准（DoD）
- 无崩溃、无维度错误、无动作越界错误
- reward 非常量零
- 策略不再完全随机游走（可观察到行为改善趋势）

## Phase 2：模型与超参优化（P1，3-5天）

### 目标
提升收敛速度与策略稳定性。

### 任务清单
1. 升级模型（优先方案A，增强 MLP）：
- 隐层扩容（如 `470 -> 256 -> 128`）
- 增加 `LayerNorm`，可选 `Dropout(0.1)`
2. 调整超参数（小步迭代）：
- `INIT_LEARNING_RATE_START`: `5e-4 ~ 1e-3`
- `BETA_START`: `0.01 ~ 0.05`
- 其余参数保持或微调（`LAMDA`, `VF_COEF`, `GRAD_CLIP`）
3. 建立单地图对比实验：
- 固定随机种子与训练时长
- 一次只改一个主因素（模型或超参）

### 交付物
- P1 模型结构版本
- 至少 3 组对比实验记录

### 验收标准（DoD）
- 平均得分高于 P0 基线
- 电量耗尽率下降
- 碰撞率下降

## Phase 3：进阶优化与泛化（P2，5-7天）

### 目标
提升多地图泛化能力并提高上限。

### 任务清单
1. 实施 CNN+MLP 混合网络（方案B）：
- 地图分支卷积编码
- 标量分支 MLP 编码
- 融合后输出 Actor/Critic
2. 引入课程学习：
- 简单地图/低机器人数量 -> 复杂地图/高机器人数量
3. 多地图训练评估：
- 随机地图训练
- 输出逐地图指标与方差

### 交付物
- CNN+MLP 网络版本
- 课程学习配置
- 多地图评估报告

### 验收标准（DoD）
- 多地图平均得分提升
- 指标方差下降
- 泛化稳定性优于 P1

## Phase 4：冲刺优化（P3，持续）

### 目标
面向竞赛成绩做精细提分。

### 任务清单
1. 超参数网格搜索（限定范围）
2. 探索增强（RND/ICM 二选一先试点）
3. 鲁棒性测试与回归

### 验收标准（DoD）
- 达成目标区间：平均得分 > 400、成功率 > 80%、碰撞率 < 10%

## 7. 风险与应对

- 风险：奖励塑形过强导致“刷局部最优”
- 应对：降低辅奖励权重，主目标保持最高权重，定期回归纯主奖励实验

- 风险：模型升级后训练不稳定
- 应对：回退到增强 MLP 版本，减小学习率与熵系数

- 风险：多变量同时改动导致无法归因
- 应对：严格执行“单因素迭代”，每次仅改一类主因素
