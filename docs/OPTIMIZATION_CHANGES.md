# Robot Vacuum 优化改动说明

## 改动日期
2026-04-11

## 优化目标
基于用户需求的三个优先级进行优化：
1. **P1 (最高)**: 充电 - 稳定学会充电行为，解决续航短板
2. **P2 (中等)**: 躲避官方机器人 - 避免碰撞失败
3. **P3 (较低)**: 扩大清扫覆盖 - 提升清扫完成度

## 改动文件
### 修改: `agent_ppo/feature/preprocessor.py`

#### 改动 1: 行为优先级特征权重调整 (第 389-415 行)
**充电驱动阈值提升**
```python
# 原: charger_weight = float(np.clip((0.55 - battery_ratio) / 0.35, 0.0, 1.0))
# 新: charger_weight = float(np.clip((0.60 - battery_ratio) / 0.35, 0.0, 1.0))
```
- **效果**: 电量在 60% 以上时就开始计算充电权重，提高充电意识
- **理由**: 早期驱动，避免电量过低才反应

**NPC 躲避灵敏度提升**
```python
# 原: evade_weight = float(np.clip((12.0 - npc_dist) / 8.0, 0.0, 1.0))
# 新: evade_weight = float(np.clip((10.0 - npc_dist) / 7.0, 0.0, 1.0))
```
- **效果**: NPC 距离在 10 格内就启动躲避行为，距离感更灵敏
- **理由**: 提高躲避反应速度，减少碰撞风险

#### 改动 2: 奖励函数重塑 (第 417-503 行)

##### 2.1 覆盖率奖励调整 (P3: 较低优先级)
```python
# 首次访问新区域:
# 原: reward += 0.07
# 新: reward += 0.10

# 重复访问过度:
# 原: elif visit_count > 4: reward -= 0.03 * min(visit_count - 4, 8)
# 新: elif visit_count > 6: reward -= 0.08 * min(visit_count - 6, 8)
```
- **改进**: 更强地鼓励探索新区域，更严厉地惩罚重复访问
- **避免**: 过度局部徘徊

##### 2.2 低电量充电驱动 (P1: 最高优先级) - 核心改动
```python
# 触发阈值:

# 新: if battery_ratio < 0.55 and not self._low_battery_active:

# 危险低电量惩罚:
# 原: reward -= 0.40 * float(...)
```

  - 更早(55% 而非 45%)开始引导充电
  - 更强(+5.0 而非 +4.0)奖励成功充电
  - 更大惩罚远离充电桩的危险行为
- **效果**: 使智能体优先学会稳定的充电循环

##### 2.3 NPC 躲避奖励强化 (P2: 中等优先级)
```python
# 基础躲避惩罚:
# 原: reward -= 1.00 * ((10.0 - min_npc_dist) / 10.0)
# 新: reward -= 1.50 * ((10.0 - min_npc_dist) / 10.0)

# 逃脱奖励:
# 原: reward += 0.35 * float(np.clip(npc_escape_delta / 4.0, -1.0, 1.0))
# 新: reward += 0.60 * float(np.clip(npc_escape_delta / 4.0, -1.0, 1.0))

# 新增: 极近距离额外惩罚

```
- **改进**:
  - 强化躲避紧迫性 (-1.50 而非 -1.00)
  - 增加逃脱成功的奖励 (+0.60 而非 +0.35)
  - 对极近距离 (<6格) 增加额外惩罚 (-2.00)
- **效果**: 更有力地教导智能体避免 NPC 碰撞

## 预期效果
### 立即影响 (episode 层面)
- 低电量时更频繁地尝试靠近充电桩
- 离官方机器人更快速地转向逃离
- 优先探索新区域而非重复游走

### 中期效果 (百局级别)
- `charge_success_cnt` 显著提升 (目标: > 15%)
- `charge_attempt_cnt` 提升 (目标: > 20%)
- `near_npc_steps` 下降
- `stuck_cnt` 下降

### 长期效果 (万局训练)
- 稳定学会"清扫 → 充电 → 再清扫"的闭环
- 胜率从 ~0.9% 提升至 >= 5%
- 清扫覆盖率提升，完成度提高
