## 一、项目概述

### 1.1 任务目标

**路径规划 - 区域覆盖问题**

训练小悟机器人在 128×128 栅格地图上，规定时间内清扫尽可能多的污渍地面。

| 核心指标 | 说明 |
|---------|------|
| **清扫得分** | 每清扫1格污渍 +1分，官方机器人清扫的不计分 |
| **生存约束** | 避免电量耗尽（初始200，每步-1） |
| **安全约束** | 避免与官方机器人碰撞（进入3×3范围即失败） |

### 1.2 终止条件

| 终止原因 | 状态 | 说明 |
|---------|------|------|
| 达到最大步数 | ✅ completed | 正常完成（默认1000步） |
| 电量耗尽 | ❌ failed | battery ≤ 0 |
| 碰撞官方机器人 | ❌ failed | 进入NPC 3×3范围 |

## 二、环境数据协议

### 2.1 观测数据结构 (env_obs)

```python
env_obs = {
    "step_no": int,                    # 当前步数
    "frame_state": {
        "heroes": {                    # 小悟机器人状态
            "pos": {"x": int, "z": int},
            "battery": int,            # 当前电量 (0-200)
            "battery_max": int,        # 电量上限
            "score": int,              # 当前得分
            "dirt_cleaned": int        # 已清扫污渍数
        },
        "npcs": [                      # 官方机器人列表 (最多4个)
            {"pos": {"x": int, "z": int}, "idx": int}
        ],
        "organs": [                    # 充电桩列表 (3×3每个)
            {"pos": {"x": int, "z": int}, "w": 3, "h": 3}
        ]
    },
    "env_info": {
        "total_score": int,            # 总得分
        "total_dirt": int,             # 污渍总数
        "remaining_charge": int,       # 剩余电量
        "charge_count": int,           # 充电次数
        "max_step": int,               # 最大步数
        "step_cleaned_cells": [...]    # 本步清扫坐标
    },
    "map_info": [[int] * 21] * 21,     # 21×21视野网格
    "legal_act": [int] * 8,            # 8方向合法动作掩码
    "terminated": bool,
    "truncated": bool
}
```

### 2.2 视野网格值

| 值 | 含义 |
|----|------|
| 0 | 障碍物/边界（不可通行） |
| 1 | 已清扫道路 |
| 2 | 污渍地面（未清扫） |

### 2.3 动作空间 (8方向)

```
        2(↑)
    3(↖)   1(↗)
  4(←) [P] 0(→)
    5(↙)   7(↘)
        6(↓)
```

| 动作 | 方向 | 位移(dx, dz) |
|------|------|-------------|
| 0 | 右 → | (1, 0) |
| 1 | 右上 ↗ | (1, -1) |
| 2 | 上 ↑ | (0, -1) |
| 3 | 左上 ↖ | (-1, -1) |
| 4 | 左 ← | (-1, 0) |
| 5 | 左下 ↙ | (-1, 1) |
| 6 | 下 ↓ | (0, 1) |
| 7 | 右下 ↘ | (1, 1) |

#### 4.1.2 特征设计方案 (preprocessor.py)

**推荐特征维度：470维**

| 特征类别 | 维度 | 来源 | 处理方式 |
|---------|------|------|---------|
| 地图视野 | 441 | map_info (21×21) | flatten, /2.0归一化 |
| 电量比例 | 1 | battery/battery_max | 0~1 |
| 步数比例 | 1 | step_no/max_step | 0~1 |
| 当前位置 | 2 | heroes.pos | /128归一化 |
| 清扫进度 | 1 | score/total_dirt | 0~1 |
| 充电桩距离 | 4 | 计算到4个充电桩距离 | /180归一化 |
| NPC距离 | 4 | 计算到4个NPC距离 | /180归一化 |
| NPC方向 | 8 | 4个NPC的相对方向 | sin/cos编码 |
| 上步动作 | 8 | last_action | one-hot |
| **合计** | **470** | | |

**特征提取伪代码：**

```python
def feature_process(self, env_obs, last_action):
    obs = env_obs
    frame = obs["frame_state"]
    heroes = frame["heroes"]
    
    # 1. 地图特征 (441维)
    map_flat = np.array(obs["map_info"]).flatten() / 2.0
    
    # 2. 状态特征
    battery_ratio = heroes["battery"] / heroes["battery_max"]
    step_ratio = obs["step_no"] / obs["env_info"]["max_step"]
    pos_x = heroes["pos"]["x"] / 128.0
    pos_z = heroes["pos"]["z"] / 128.0
    clean_ratio = heroes["score"] / max(obs["env_info"]["total_dirt"], 1)
    
    # 3. 充电桩特征 (4维)
    charger_dists = []
    for organ in frame["organs"]:
        dx = organ["pos"]["x"] - heroes["pos"]["x"]
        dz = organ["pos"]["z"] - heroes["pos"]["z"]
        dist = np.sqrt(dx**2 + dz**2) / 180.0
        charger_dists.append(dist)
    
    # 4. NPC特征 (12维: 4距离 + 8方向)
    npc_dists = []
    npc_dirs = []
    for npc in frame["npcs"]:
        dx = npc["pos"]["x"] - heroes["pos"]["x"]
        dz = npc["pos"]["z"] - heroes["pos"]["z"]
        dist = np.sqrt(dx**2 + dz**2) / 180.0
        npc_dists.append(dist)
        angle = np.arctan2(dz, dx)
        npc_dirs.extend([np.sin(angle), np.cos(angle)])
    
    # 5. 上步动作 (8维 one-hot)
    last_act_onehot = np.zeros(8)
    if last_action >= 0:
        last_act_onehot[last_action] = 1.0
    
    # 拼接特征
    feature = np.concatenate([
        map_flat,                           # 441
        [battery_ratio, step_ratio],        # 2
        [pos_x, pos_z],                     # 2
        [clean_ratio],                      # 1
        charger_dists,                      # 4
        npc_dists,                          # 4
        npc_dirs,                           # 8
        last_act_onehot                     # 8
    ]).astype(np.float32)
    
    legal_action = obs["legal_act"]
    return feature, legal_action
```

#### 4.1.3 奖励设计方案 (preprocessor.py)

**多目标奖励函数：**

```python
def compute_reward(self, env_obs, prev_obs, terminated, truncated):
    reward = 0.0
    heroes = env_obs["frame_state"]["heroes"]
    env_info = env_obs["env_info"]
    
    # 1. 清扫奖励（核心目标）
    cleaned_this_step = len(env_info.get("step_cleaned_cells", []))
    reward += 1.0 * cleaned_this_step
    
    # 2. 时间惩罚（鼓励效率）
    reward -= 0.01
    
    # 3. 电量管理
    battery_ratio = heroes["battery"] / heroes["battery_max"]
    if battery_ratio < 0.2:
        # 低电量时接近充电桩给正奖励
        min_charger_dist = self._min_charger_distance(env_obs)
        if min_charger_dist < 10:
            reward += 0.1 * (10 - min_charger_dist) / 10
    
    # 4. NPC安全距离
    min_npc_dist = self._min_npc_distance(env_obs)
    if min_npc_dist < 5:
        reward -= 0.5 * (5 - min_npc_dist) / 5
    
    # 5. 终止惩罚
    if terminated:
        fail_reason = env_obs.get("fail_reason", "")
        if "collision" in fail_reason.lower():
            reward -= 10.0  # 碰撞NPC
        elif "battery" in fail_reason.lower():
            reward -= 5.0   # 电量耗尽
    
    return [reward]
```

**奖励权重参考：**

| 奖励项 | 权重 | 触发条件 |
|--------|------|---------|
| 清扫奖励 | +1.0/格 | 每清扫一格污渍 |
| 时间惩罚 | -0.01/步 | 每步固定 |
| 充电导航 | +0.1 | 低电量(<20%)且接近充电桩 |
| NPC躲避 | -0.5 | 距离NPC<5格 |
| 碰撞惩罚 | -10.0 | 与NPC碰撞终止 |
| 电量耗尽 | -5.0 | 电量为0终止 |
