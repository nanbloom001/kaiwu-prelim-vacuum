# 方案02：基于地图记忆与分层决策的扫地机器人赛题方案（改进版）

## 1. 文档目的

本文给出一个面向当前 `robot_vacuum` 赛题的可落地方案，针对实测中发现的**无法避开官方机器人**和**电量规划较差**两大问题，提供更具体的改进方案。

## 2. 对赛题的理解

### 2.1 环境参数
- 地图规模为 `128 x 128`。
- 智能体可见的是局部 `21 x 21` 视野。
- 动作空间为 `8` 个方向移动。
- 电量上限 `battery_max = 200`，最大步数 `max_step = 2000`。
- 存在官方机器人（其他扫地机），需避开。

### 2.2 动作编号定义
```
0: 上 (0, -1)      1: 右上 (1, -1)
2: 右 (1, 0)       3: 右下 (1, 1)
4: 下 (0, 1)       5: 左下 (-1, 1)
6: 左 (-1, 0)      7: 左上 (-1, -1)
```

### 2.3 地图元素（视野中取值）
- `0` = 障碍（墙、其他扫地机器人）
- `1` = 可通行空地
- `2` = 污渍（需要清扫）
- `3` = 充电桩

### 2.4 核心难点
- **官方机器人避障**：其他扫地机器人也会移动，需要动态避障
- **电量安全**：需要提前规划回充路径，避免半路断电
- **高效清扫**：减少重复覆盖，提高单次充电清扫效率

### 3.2 官方机器人避障策略（关键改进）

**问题**：视野中官方机器人显示为障碍(0)，会被误判为静态墙。

**解决方案**：
1. **动态障碍识别**：
   - 对比连续两帧视野，位置变化的"障碍"即为官方机器人
   - 在 `danger_map` 上标记并扩大安全范围（周围1-2格）

2. **安全缓冲区**：
   ```python
   def mark_danger_zone(self, robot_pos, radius=2):
       """标记官方机器人周围为危险区域"""
       for dx in range(-radius, radius+1):
           for dy in range(-radius, radius+1):
               if abs(dx) + abs(dy) <= radius:
                   self.danger_map[robot_pos[0]+dx, robot_pos[1]+dy] = 1
   ```

3. **路径规划时排除危险区域**：
   - A*/BFS 中将 `danger_map == 1` 的格子视为不可通行
   - 若必须靠近，优先选择距离机器人较远的一侧

4. **视野边缘警戒**：
   - 当视野边缘(21x21边界)出现官方机器人时，优先向远离方向移动
   - 避免被"堵"在墙角

### 3.3 电量规划策略（关键改进）

**核心原则**：**宁可早回充，不可半路断电**

#### 3.3.1 动态安全电量计算
```python
def calc_safe_battery_threshold(self, pos):
    """计算当前位置的安全电量阈值"""
    if not self.charger_map:
        return 50  # 未发现充电桩时的保守值
    
    # 计算到最近充电桩的最短路径距离
    nearest_charger, min_dist = self.find_nearest_charger(pos)
    
    # 安全电量 = 路径距离 + 绕障冗余 + 紧急缓冲
    safety_margin = 15  # 绕障冗余
    emergency_buffer = 10  # 紧急缓冲
    
    safe_threshold = min_dist + safety_margin + emergency_buffer
    return min(safe_threshold, 150)  # 上限150，避免过于保守
```

#### 3.3.2 开局首次回充规划（开局即规划）
```python
def init_episode(self, obs):
    """开局初始化，立即规划到最近充电桩的安全路径"""
    self.reset_maps()
    
    # 解析初始位置和充电桩位置
    self.cur_pos = parse_position(obs)
    self.charger_map = parse_chargers(obs)  # 初始视野可能看到充电桩
    
    # 如果初始电量不足以到达任意充电桩，立即向最近充电桩移动
    if self.charger_map:
        nearest, dist = self.find_nearest_charger(self.cur_pos)
        if self.battery < dist + 25:  # 电量紧张

```

#### 3.3.3 电量状态机
```python
def check_battery_status(self):
    """检查电量状态并切换模式"""
    safe_threshold = self.calc_safe_battery_threshold(self.cur_pos)
    
    if self.battery <= safe_threshold:
        # 必须回充
        self.mode = "RETURN_TO_CHARGER"
        self.target_charger = self.find_nearest_charger(self.cur_pos)[0]
        return True
    elif self.battery <= safe_threshold + 20:
        # 预警状态：就近清扫，不远离充电桩
        self.mode = "CLEAN_NEARBY"
        return False
    return False  # 电量充足，正常清扫
```

### 3.4 蛇形清扫策略（关键改进）

**问题**：圆形清扫效率低，重复路径多。

**解决方案**：**基于充电桩的局部蛇形清扫**

#### 3.4.1 蛇形清扫区域划分
```python
def get_snake_cleaning_area(self, charger_pos):
    """以充电桩为中心的蛇形清扫区域"""
    # 根据剩余电量决定清扫范围
    range_size = min(self.battery // 4, 30)  # 每4电量支持1格往返
    
    return {
        'center': charger_pos,
        'x_min': max(0, charger_pos[0] - range_size),
        'x_max': min(127, charger_pos[0] + range_size),
        'z_min': max(0, charger_pos[1] - range_size),
        'z_max': min(127, charger_pos[1] + range_size)
    }
```

#### 3.4.2 蛇形路径生成
```python
def generate_snake_path(self, area, start_pos):
    """生成蛇形清扫路径"""
    path = []
    x_min, x_max = area['x_min'], area['x_max']
    z_min, z_max = area['z_min'], area['z_max']
    
    # 确定清扫方向（水平或垂直）
    # 选择能清扫更多格子的方向
    if (x_max - x_min) >= (z_max - z_min):
        # 水平蛇形：左右来回，逐步上下移动
        direction = 1  # 1=向右, -1=向左
        z = z_min
        while z <= z_max:
            if direction == 1:
                path.append((x_max, z))
            else:
                path.append((x_min, z))
            
            # 检查是否需要转向
            if (direction == 1 and x_max - x_min > 0) or \
               (direction == -1 and x_max - x_min > 0):
                z += 1
                if z <= z_max:
                    # 上下移动一步
                    path.append((path[-1][0], z))
                direction *= -1
            else:
                break
    else:
        # 垂直蛇形：上下来回，逐步左右移动
        # 类似实现...
        pass
    
    return path
```

#### 3.4.3 实际蛇形清扫执行（类似用户示例）
```python
def execute_snake_cleaning(self, charger_pos):
    """执行蛇形清扫：充满电后从充电桩出发，扫完一片区域后返回"""
    
    # 步骤1：检查电量是否满电或接近满电
    if self.battery < self.battery_max * 0.9:
        # 不是满电状态，先回充电桩
        if self.cur_pos != charger_pos:
            return self.move_to(charger_pos)
        else:
            # 在充电桩充电，等待充满
            return "STAY"  # 或者做小幅移动等待
    
    # 步骤2：确定清扫区域
    if not self.current_cleaning_area:
        self.current_cleaning_area = self.get_snake_cleaning_area(charger_pos)
        self.snake_path = self.generate_snake_path(self.current_cleaning_area, self.cur_pos)
        self.snake_path_index = 0
    
    # 步骤3：计算安全返回电量
    safe_return_battery = self.calc_safe_battery_threshold(self.cur_pos)
    
    # 步骤4：执行蛇形路径或提前返航
    if self.battery <= safe_return_battery:
        # 电量不足，立即返航
        self.current_cleaning_area = None
        self.snake_path = []
        return self.move_to(charger_pos)
    
    # 执行蛇形路径下一步
    if self.snake_path_index < len(self.snake_path):
        target = self.snake_path[self.snake_path_index]
        if self.cur_pos == target:
            self.snake_path_index += 1
            target = self.snake_path[self.snake_path_index] if self.snake_path_index < len(self.snake_path) else charger_pos
        return self.move_to(target)
    else:
        # 本区域清扫完成，返回充电桩
        self.current_cleaning_area = None
        return self.move_to(charger_pos)
```

### 3.5 充电桩优先级策略

**原则**：先清扫当前充电桩附近区域，再去下一个充电桩。

```python
def select_next_target_charger(self):
    """选择下一个目标充电桩（优先未探索区域）"""
    candidates = []
    for charger in self.charger_map:
        # 计算该充电桩周围未清扫区域比例
        area = self.get_snake_cleaning_area(charger)
        uncleaned_ratio = self.calc_uncleaned_ratio(area)
        distance = self.manhattan_distance(self.cur_pos, charger)
        
        # 评分：未清扫比例越高越好，距离越近越好
        score = uncleaned_ratio * 100 - distance * 0.5
        candidates.append((charger, score))
    
    # 选择评分最高的
    candidates.sort(key=lambda x: x[1], reverse=True)
    return candidates[0][0] if candidates else None

def should_switch_charger(self):
    """判断是否该切换到下一个充电桩"""
    # 当前充电桩附近已基本清扫完毕
    current_area_cleaned = self.calc_cleaned_ratio(self.current_cleaning_area) > 0.85
    
    # 或当前充电桩附近没有更多可清扫区域
    no_more_dirt = self.find_nearest_dirt_in_area(self.current_cleaning_area) is None
    
    # 且电量不足以去更远的地方
    safe_threshold = self.calc_safe_battery_threshold(self.cur_pos)
    battery_low = self.battery < safe_threshold + 30
    
    return (current_area_cleaned or no_more_dirt) and battery_low
```

```python
class ModeManager:
    MODES = {
        'EMERGENCY_RETURN': 0,    # 紧急返航（电量极低）
        'RETURN_TO_CHARGER': 1,   # 正常返航
        'AVOID_ROBOT': 2,         # 避让官方机器人
        'STUCK_RECOVERY': 3,      # 脱困模式
        'SNAKE_CLEANING': 4,      # 蛇形清扫
        'DIRECT_CLEANING': 5,     # 直接清扫（视野内有污渍）
        'EXPLORATION': 6,         # 探索未知区域
    }
    
    def decide_mode(self, obs):
        """模式优先级判断"""
        # P0: 电量危机
        if self.battery <= self.calc_safe_battery_threshold(self.cur_pos):
            return 'EMERGENCY_RETURN' if self.battery < 20 else 'RETURN_TO_CHARGER'
        
        # P1: 官方机器人避让
        if self.detect_official_robot_nearby(obs, danger_distance=3):
            return 'AVOID_ROBOT'
        
        # P2: 卡死检测
        if self.is_stuck():
            return 'STUCK_RECOVERY'
        
        # P3: 视野内有污渍 - 直接清扫
        if self.has_visible_dirt(obs):
            return 'DIRECT_CLEANING'
        
        # P4: 蛇形清扫模式（如果当前在某个充电桩的清扫区域内）
        if self.current_cleaning_area and self.battery > self.calc_safe_battery_threshold(self.cur_pos) + 30:
            return 'SNAKE_CLEANING'
        
        # P5: 探索
        return 'EXPLORATION'
```

## 5. 路径规划增强

### 5.1 A* 路径规划（带危险区域避让）
```python
def a_star_path(self, start, goal, avoid_danger=True):
    """A*路径规划，支持危险区域避让"""
    open_set = [(0, start)]
    came_from = {}
    g_score = {start: 0}
    f_score = {start: self.heuristic(start, goal)}
    
    while open_set:
        _, current = heapq.heappop(open_set)
        
        if current == goal:
            return self.reconstruct_path(came_from, current)
        
        for neighbor in self.get_neighbors(current):
            # 检查是否为障碍
            if self.obstacle_map[neighbor] == 1:
                continue
            
            # 检查是否为危险区域（官方机器人附近）
            if avoid_danger and self.danger_map[neighbor] == 1:
                continue
            
            tentative_g = g_score[current] + 1
            
            if neighbor not in g_score or tentative_g < g_score[neighbor]:
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                f_score[neighbor] = tentative_g + self.heuristic(neighbor, goal)
                heapq.heappush(open_set, (f_score[neighbor], neighbor))
    
    return None  # 无路径
```

### 5.2 动作选择（8方向）
```python
def get_action_towards(self, target_pos):
    """获取朝向目标位置的动作"""
    dx = target_pos[0] - self.cur_pos[0]
    dz = target_pos[1] - self.cur_pos[1]
    
    # 归一化到-1,0,1
    dx = max(-1, min(1, dx))
    dz = max(-1, min(1, dz))
    
    # 映射到动作编号
    action_map = {
        (0, -1): 0,   # 上
        (1, -1): 1,   # 右上
        (1, 0): 2,    # 右
        (1, 1): 3,    # 右下
        (0, 1): 4,    # 下
        (-1, 1): 5,   # 左下
        (-1, 0): 6,   # 左
        (-1, -1): 7,  # 左上
    }
    
    desired_action = action_map.get((dx, dz), 0)
    
    # 检查合法性
    if self.legal_actions[desired_action] == 1:
        return desired_action
    
    # 尝试邻近动作
    alternatives = self.get_alternative_actions(desired_action)
    for alt in alternatives:
        if self.legal_actions[alt] == 1:
            return alt
    
    # 选择任意合法动作
    for i, legal in enumerate(self.legal_actions):
        if legal == 1:
            return i
    
    return 0
```

## 6. 脱困策略

```python
def is_stuck(self):
    """检测是否卡住"""
    if len(self.position_history) < 10:
        return False
    
    recent_positions = self.position_history[-10:]
    unique_positions = set(recent_positions)
    
    # 10步内移动范围小于3格视为卡住
    if len(unique_positions) < 3:
        return True
    
    # 或者频繁来回移动
    if self.detect_oscillation():
        return True
    
    return False

def stuck_recovery(self):
    """脱困动作"""
    # 增加访问计数惩罚
    for pos in self.position_history[-5:]:
        self.visit_count_map[pos] += 10
    
    # 优先选择访问次数少且合法的动作
    scores = []
    for action in range(8):
        if self.legal_actions[action] == 0:
            scores.append(-9999)
            continue
        next_pos = self.get_next_position(self.cur_pos, action)
        score = -self.visit_count_map[next_pos] + random.random() * 0.1
        scores.append(score)
    
    return scores.index(max(scores))
```

## 9. 总结

本改进方案针对实测问题提供以下核心改进：

1. **官方机器人避让**：通过动态检测和危险地图，有效避免碰撞
2. **电量安全规划**：开局即规划，动态计算安全阈值，确保总能返回充电桩
3. **蛇形高效清扫**：减少重复路径，提高单次充电清扫覆盖率
4. **充电桩区域管理**：先扫完一个区域再去下一个，避免频繁往返

实施顺序建议：**P0电量安全 > P0官方机器人避让 > P1蛇形清扫 > P1充电桩区域管理**。
