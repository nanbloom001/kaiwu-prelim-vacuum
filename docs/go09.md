# go09

目标：将当前单一目标配置训练的主策略明确收敛为三层优先级，并据此调整 reward / planner。

当前目标配置：

- `robot_count = 4`
- `charger_count = 3`
- `max_step = 1000`
- `battery_max = 150`

## 1. 当前主策略

当前主策略按优先级定义为：

1. **先保证电量稳定**
   - 充电前电量过低：惩罚
   - 充电前电量处于合理区间：奖励
   - 充电前电量过高：惩罚

2. **在保证电量的基础上规避官方机器人**
   - 避免高风险碰撞
   - 在低电量下进一步提高避险优先级

3. **在存活前提下最大化探索与清扫效率**
   - 奖励有效探索
   - 奖励中后段持续清扫
   - 惩罚重复走位和无效巡航

也就是说：

- 电量安全优先于一切
- 存活率高于探索效率
- 探索奖励必须排在“电量安全 + 避险”之后

### 2.2 reward 调整

本轮 reward 的调整方向是：

- 继续保留电量优先
- 在此基础上减少“过度保守”漂移
- 让中后段仍愿意高效清扫

具体包括：

#### 1. 目标配置保守压力小幅下调

```python
safety_pressure = resource_pressure - 0.16 * target_profile_boost
```

作用：

- 对当前目标桶 `4 / 3 / 1000 / 150`
- 不再继续把策略推向过早保守

#### 2. 中后段探索/清扫奖励增强

```python
explore_reward * (1.0 + 0.22 * target_profile_boost)
late_game_efficiency_reward = 0.07 + 0.04 * target_profile_boost
late_progress_reward = 0.02 * ...
```

作用：

- 在后半段继续强化有效探索与清扫
- 避免“只活着，不干活”

#### 3. 过早充电惩罚增强

在：

- `prev_battery_ratio <= 0.60`

区间，进一步加重早充惩罚。

作用：

- 减少“电量刚有压力就提前回桩”的行为

#### 4. 危险惩罚小幅缓和

```python
low_battery_penalty
critical_battery_penalty
step_penalty
```

都比上一轮更温和一些。

作用：

- 防止 reward 继续单边推动策略向保命塌缩

### 2.3 planner 小回调

对当前目标配置：

- `effective_return_margin` 小幅减 `2.0`
- `effective_low_battery_ratio` 小幅减 `0.015`

作用：

- 不改变 charge 阶段安全边界
- 但避免一部分本可继续安全清扫的局过早进入 `charge`

## 3. 设计意图

这一轮不是否定“保命优先”，而是：

- 在保命优先的前提下
- 把策略从“过度保守”拉回到“安全且高效”

换句话说：

- 不是降低电量优先级
- 而是降低“过度保守”的吸引力

## 4. 当前边界

这一轮没有做：

- 新的训练分布修改
- 网络结构修改
- PPO 主参数修改

所以 go09 的本质是：

- **围绕既定主策略做 reward + planner 的平衡微调**
