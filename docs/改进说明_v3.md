# 清扫机器人智能体改进说明 v3.0 - 基于赛题规则

## 赛题规则要点

根据提供的赛题信息，关键规则如下：

1. **充电桩规则**：
   - 4个充电桩，每个占 3×3 格
   - 机器人进入充电桩 3×3 范围，立即充满电（200电量）

2. **官方机器人规则**：
   - 4个官方机器人，在 21×21 区域内随机移动
   - 碰撞判定：小悟机器人进入官方机器人的 3×3 范围即算碰撞（距离≤1格）
   - 官方机器人清扫过的地面，小悟再清扫无效

3. **其他规则**：
   - 地图 128×128，电量 200，步数 1000
   - 视野 21×21，8方向移动

## 主要改进

### 1. 充电桩 3×3 范围检测

**改进内容**：
- 充电桩检测从点检测改为 3×3 范围检测
- 计算到充电桩距离时，计算到 3×3 范围边缘的距离
- 存储每个充电桩的完整 3×3 范围

**关键代码**：
```python
CHARGER_RADIUS = 1  # 3×3对应半径1

def _is_on_charger(self, robot_pos):
    """检查是否在充电桩3×3范围内"""
    for charger_center in self.charger_map:
        if abs(robot_pos[0] - charger_center[0]) <= CHARGER_RADIUS and \
           abs(robot_pos[1] - charger_center[1]) <= CHARGER_RADIUS:
            return True
    return False
```

**效果**：
- 更准确地判断是否可以充电
- 路径规划时更精确地计算到充电桩的距离

### 2. 官方机器人 3×3 碰撞检测

**改进内容**：
- 危险区域从单点扩展为 3×3 范围
- 危险图预测也使用 3×3 范围
- 新增 `_is_in_robot_danger_zone()` 方法检测是否在危险范围内

**关键代码**：
```python
ROBOT_COLLISION_RADIUS = 1  # 3×3碰撞范围

def _is_in_robot_danger_zone(self, pos):
    """检查位置是否在官方机器人的3×3危险范围内"""
    for robot_pos in self.robot_positions:
        if abs(pos[0] - robot_pos[0]) <= ROBOT_COLLISION_RADIUS and \
           abs(pos[1] - robot_pos[1]) <= ROBOT_COLLISION_RADIUS:
            return True
    return False
```

**效果**：
- 更早发现碰撞风险
- 更保守的避障策略，提高安全性

### 3. 记录官方机器人清扫区域

**改进内容**：
- 新增 `official_cleaned_map` 记录官方机器人清扫过的区域
- 在更新地图时，检测脏点消失但非自己清扫的情况
- 路径规划时避开官方机器人已清扫区域
- 动作选择时惩罚前往已清扫区域的动作

**关键代码**：
```python
# 在_update_memory_maps中
def _update_memory_maps(self, robot_pos, local_view):
    # ... 其他代码 ...
    if dirt:
        self.dirt_map[gy, gx] = 1
    elif self.dirt_map[gy, gx] == 1:
        # 脏点被清除
        self.dirt_map[gy, gx] = 0
        # 检查是否是我们自己清扫的
        if abs(gx - robot_pos[0]) <= 1 and abs(gy - robot_pos[1]) <= 1:
            self.cleaned_map[gy, gx] = 1
            self.total_cleaned += 1
        else:
            # 是官方机器人清扫的
            self.official_cleaned_map[gy, gx] = 1

# 在路径规划中增加惩罚
if self.official_cleaned_map[neighbor[1], neighbor[0]] == 1:
    move_cost += 2.0  # 增加经过已清扫区域的成本
```

**效果**：
- 避免无效清扫，提高效率
- 路径规划优先选择未清扫区域
- 单位电量清扫得分更高

### 4. 调整充电策略（适应3×3充电桩）

**改进内容**：
- 降低提前充电阈值（65% → 55%），因为充电桩范围更大更容易到达
- 增加触发距离（8 → 12），考虑3×3范围
- 降低最小清扫步数（15 → 10）
- 降低安全电量冗余（DETOUR_MARGIN: 6→5, UNKNOWN_MARGIN: 4→3）

**关键参数**：
```python
EARLY_CHARGE_THRESHOLD = 0.55   # 降低到55%
CHARGE_NEAR_DISTANCE = 12       # 增加到12
MIN_CLEAN_BEFORE_CHARGE = 10    # 降低到10步
DETOUR_MARGIN = 5               # 降低冗余
UNKNOWN_MARGIN = 3
```

**效果**：
- 更积极地利用充电桩
- 更频繁地充电，保持高电量状态
- 减少因电量不足导致的失败

### 5. 优化探索策略

**改进内容**：
- 优先寻找4个充电桩（原来是2个）
- 增加探索半径（20 → 25）
- 降低换桩覆盖率阈值（85% → 80%），更快切换区域
- 在探索目标选择中增加对官方已清扫区域的惩罚

**关键代码**：

**效果**：
- 更快发现所有充电桩
- 优先清扫高价值区域（未被官方机器人清扫）
- 提高整体清扫效率

## 测试建议

1. **充电行为测试**：
   - 检查机器人是否能准确识别3×3充电桩范围
   - 观察是否更频繁地充电

2. **避障测试**：
   - 确保机器人始终保持与官方机器人1格以上距离
   - 检查是否会提前避开官方机器人的3×3范围

3. **清扫效率测试**：
   - 观察是否避开官方机器人已清扫区域
   - 检查单位电量的清扫得分

4. **监控指标**：
   - 充电次数（应比之前更多）
   - 碰撞次数（应为0）
   - 无效清扫次数（应降低）
   - 总清扫得分（应提高）

## 注意事项

1. **保守的避障策略**：由于3×3碰撞范围较大，避障策略相应更保守，可能会略微降低清扫速度，但安全性更高。

2. **充电桩检测准确性**：确保环境中充电桩确实是3×3范围，否则充电检测可能失效。

3. **官方机器人清扫检测**：通过脏点消失且非自己清扫来推断，可能存在一定延迟，但不影响整体策略。

4. **参数微调**：如果发现充电过于频繁或避障过于保守，可以适当调整 `EARLY_CHARGE_THRESHOLD` 和 `ROBOT_DANGER_BLOCK_TH`。
