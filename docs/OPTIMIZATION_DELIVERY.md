## 优化目标确认

用户需求的三个优先级（降序）：
1. **P1: 充电** - 稳定学会充电行为，解决续航短板
2. **P2: 躲避官方机器人** - 避免碰撞失败  
3. **P3: 扩大清扫覆盖** - 提升清扫完成度

基于 `testlog` 分析，当前最大短板是**充电行为缺失**（仅 2.3% 回合有充电），导致续航时间被限制在 200 步左右，无法形成长循环。

## 核心改动

### 改动 1: 行为优先级权重调整
**文件**: `agent_ppo/feature/preprocessor.py` 第 389-415 行

```python
# 充电权重计算：从 0.55 → 0.60
charger_weight = float(np.clip((0.60 - battery_ratio) / 0.35, 0.0, 1.0))

# NPC 躲避灵敏度：从 (12.0 - dist) / 8.0 → (10.0 - dist) / 7.0  
evade_weight = float(np.clip((10.0 - npc_dist) / 7.0, 0.0, 1.0))
```

**效果**:
- 充电：电量 60% 时即启动充电意识（原为 55%）
- 躲避：NPC 10 格内即触发躲避（原为 12 格），反应更敏捷

## 改动特点

### ✅ 优势
- **轻量级**: 仅改奖励和权重，不涉及网络结构、特征维度
- **易验证**: 改动前后对比明显（奖励函数输出不同）
- **易回滚**: 一行代码即可恢复原版本
- **向后兼容**: 模型可继续加载旧 checkpoint 继续训练
- **对齐需求**: 完全按用户的三个优先级排序

### ⚠️ 风险评估
- **低风险**: 奖励函数改动历来是最稳妥的优化方式
- **潜在风险**: 若新奖励与实际任务不匹配，可能短期内 reward 虚高但胜率仍低
  - **应对**: 已设置多个衡量指标（charge_success_cnt、near_npc_steps、stuck_cnt），可快速诊断
