## 0. 当前问题画像（基于现状代码与日志）

核心症状：
- 全地图轨迹覆盖率低，策略容易在局部区域重复游走。
- 低电量时充电行为不稳定，常见“继续清扫直到耗尽”。
- 撞墙/卡边后出现原地打转或小范围振荡。

高概率机制原因：
- 覆盖率未被直接建模与奖励约束，策略只追逐短期可见污渍收益。
- 低电量引导仅在近充电桩时有效，远距离导航信号弱。
- 缺少“卡死/重复轨迹”惩罚与“脱困成功”正反馈。
- 终局奖励与过程奖励耦合偏弱，对“安全完成+高覆盖”的导向不够强。

## 1. 目标与量化验收

P1（单图稳定）：
- 覆盖率（Visited Cells / Reachable Cells）提升到 `>= 55%`
- 充电成功率（低电量后成功补能）`>= 70%`
- 卡死率（连续 N 步位移半径过小）`<= 20%`

P2（多图泛化）：
- 多地图平均覆盖率 `>= 60%`，方差下降 `>= 20%`
- 电量耗尽失败率 `<= 15%`
- 撞墙后 20 步内脱困率 `>= 80%`

P3（冲刺）：
- 覆盖率、得分、成功率三指标同时提升，不以单指标牺牲为代价。

## 2. P1：行为矫正优先（覆盖率/充电/脱困）

### 2.1 奖励重构优先级
1. 增加“新访问格”奖励（首次访问可行区域给小正奖）。
2. 增加“重复访问惩罚”（短窗口内重复位置惩罚递增）。
3. 增加“低电量远距离导航奖励”：
   - 低电量阈值触发后，按“到最近充电桩距离下降量”给奖励。
4. 增加“卡死惩罚 + 脱困奖励”：
   - 连续 K 步位移不足阈值判定卡死；
   - 逃离卡死状态给一次性正奖。

### 2.2 特征增强优先级
1. 加入短时记忆特征：最近动作直方图、最近位置变化量、最近重复访问率。
2. 加入目标导向特征：最近充电桩方向向量、最近未清扫区域方向提示。
3. 加入风险特征：墙体接近度、可行动作数量（局部可行空间）。

### 2.3 实验矩阵（每次只改一个主因素）
- A组：仅覆盖率奖励
- B组：A + 低电量距离差奖励
- C组：B + 卡死惩罚/脱困奖励
- D组：C + 记忆型特征

固定训练预算、地图与随机种子，比较覆盖率/充电成功率/卡死率三主指标。

## 3. P2：泛化与稳定性提升

### 3.1 课程学习
- 阶段1：低机器人数、少障碍图，聚焦“高覆盖+不耗尽”。
- 阶段2：标准地图与机器人数，强化充电策略。
- 阶段3：复杂地图随机化，强化脱困鲁棒性。

### 3.2 评估拆分
- 地图级报表：每张地图输出覆盖率、成功率、碰撞率、耗尽率。
- 行为级报表：卡死触发次数、平均脱困步数、充电触发后成功率。

### 3.3 稳定性策略
- 熵系数分段退火（前期探索高，后期收敛稳）。
- 终局奖励与过程奖励比例回归检查，避免“过程刷分、终局失败”。

## 4. P3：冲刺提分

### 4.1 超参小网格
- 学习率：`3e-4 / 5e-4 / 7e-4`
- 熵系数：`0.005 / 0.01 / 0.02`
- 每组至少重复 3 次，取均值和方差。

### 4.2 行为专项冲刺
- 覆盖率专项：提高首次访问奖励占比，控制重复惩罚上限。
- 充电专项：低电量阈值与导航奖励斜率联合调优。
- 脱困专项：卡死检测窗口与惩罚强度调优。

### 4.3 回归门禁
- 任一方案若导致成功率或耗尽率显著恶化，直接回滚。
- 仅保留“覆盖率、成功率、稳定性”三者同时不退化的版本。

## 5. 实施节奏（建议）

第1周（P1）：行为矫正四组实验，确定首个可用版本。  
第2周（P2）：课程学习 + 多地图评估，固化泛化版本。  
第3周（P3）：小网格冲刺 + 回归门禁，产出提交候选。
