## 1. 当前基线的总体结构

当前基线不是简单 PPO，也不是纯规则系统，而是：

- `PPO + planner-guided residual policy`
- `77D` 特征输入
- `规则 planner 提供动作先验`
- `策略网络做 residual 混合`
- `reward shaping` 重点围绕清扫效率、探索增益、充电时机

也就是说，当前 baseline 的主策略范式已经是：

1. planner 决定大方向
2. policy 在安全空间内做细化
3. 训练目标是先稳住完成率与步数，再逐步抬高分数

## 2. 代码主链路

当前 Agent 的核心机制：

```python

```

### 2.2 PPO 训练

- [code/agent_ppo/algorithm/algorithm.py](E:\competition\kaiwuFinal\26fwwb\code\agent_ppo\algorithm\algorithm.py)

当前训练形式：

- 标准 PPO clip
- 额外引入 `planner_prob`
- 额外引入 `mix_alpha`
- 使用 behavior cloning regularization 去约束 policy 不要偏离 planner 太远

即：

- policy 不是完全自由学习
- 而是在 planner 先验上做逐步放权

## 5. 当前 reward shaping

当前 reward 重点不是纯清扫数，而是“清扫 + 探索 + 充电时机”。

主要项包括：

- `cleaning_reward`
- `explore_reward`
- `approach_reward`
- `charge_efficiency_reward`
- `charge_event_reward`
- `low_battery_penalty`
- `critical_battery_penalty`
- `revisit_penalty`
- `step_penalty`

### 5.1 充电 sweet zone 逻辑

当前 baseline 的核心特征之一，是已经把充电行为做了分段奖惩：

- 太晚充：惩罚
- 甜区充：奖励
- 太早充：惩罚

关键区间大致是：

- `target_low = 0.32`
- `target_high = 0.58`

并且只有发生真实充电时：

```python
charge_gain_ratio > 0.015
```

才触发 `charge_event_reward`

### 5.2 baseline 的 reward 目标

这个版本 reward 的主要目标不是极限刷分，而是：

- 形成更稳定的回桩节奏
- 避免 `remaining_charge = 0`
- 减少 finished_steps 和分数一起塌局

planner 实现在：

当前关键特征：

- NPC 危险区规避

### 6.1 关键阈值

当前基线参数为：

```python
BASE_RETURN_MARGIN = 22.0
NPC_RETURN_MARGIN = 28.0
LOW_BATTERY_RATIO = 0.30
EXIT_RETURN_RATIO = 0.95
HARD_NPC_RADIUS = 2
PATH_RISK_RADIUS = 4
AGGRESSIVE_EDGE_STEPS = 500
```

这说明当前 baseline 的 planner 是：

- 中等偏保守
- 会在 charger 距离 + margin 下决定回桩
- 会对 NPC 风险区进行显式屏蔽
- 但还没有做配置条件化阈值

### 6.2 planner 的作用边界

当前版本不是纯 planner 执行，而是：

- planner 给 `action_scores`
- planner 给 `safe_action_mask`
- planner 给 `target_mode`
- 最终动作仍经过 residual PPO 混合

因此它是“强先验”，不是“硬接管”。

- 特征维度稳定
- 模型结构稳定
- reward 目标清晰

## 11. 当前 baseline 的主要限制

这个 baseline 同时也有明显边界：

- 不具备显式配置感知能力
- 泛化到 `charger_count / max_step / battery_max` 变化时风险较大
- 对少数地图最差局仍然可能不稳
- 默认 zip 打包链路在当前环境里存在运行层异常

所以后续改动如果要做：

- 泛化增强
- 配置随机化
- 条件化回桩阈值

都应该明确标注为“相对 go00 baseline 的新增能力”，而不是混入基线定义本身。
