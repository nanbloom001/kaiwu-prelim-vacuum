# go13

目标：基于 2026-04-24 当前训练日志，针对现阶段最突出的两个问题提出下一轮优化方案：

- `charge` 模式下的短局失败
- 第 2 / 第 3 个充电桩到达过晚

---

## 1. 日志结论

从最新训练日志看，当前策略已经具备：

- 跑满 `max_step=1000`
- 在三充电桩地图上到达多个充电桩
- 拿到 `850~950` 左右分数

但还没有达到“稳定收敛”的状态，主要表现为：

1. 同阶段存在明显双峰
   - 一部分局能稳定 `1000` 步
   - 一部分局在 `150~300` 步直接失败
2. 短局失败高度集中在 `charge` 模式
3. 多充电桩利用存在明显波动
   - 有些局能到达 3 个桩
   - 有些局只到达 1 个桩也能跑满
4. 第 2 / 第 3 个桩经常到得太晚
   - 到达行为存在，但时机偏后

所以 go13 不再把重点放在“是否能发现新桩”，而是放在：

- **更早、更稳地利用多充电桩资源**

---

## 2. go13 核心判断

当前问题的本质不是 PPO 优化器不稳定，而是策略行为层仍存在局部最优。

具体来说：

### 2.1 现有 go12 解决了“看见不等于有效利用”的一部分问题

go12 把奖励从“发现充电桩”改成了“首次到达充电桩”，这是正确方向。

但 go12 仍然存在一个限制：

- 奖励只在“到达之后”才出现
- 对“应该更早去到第 2 / 第 3 个桩”缺少前置引导

所以它改善了结果，但还不能稳定改善时机。

### 2.2 `charge` 模式失败说明返航决策仍然偏晚或路径偏脆弱

日志里很多短局失败具有共同点：

- 失败时 `mode=charge`
- 有些局甚至 `charger_arrivals=0`

这意味着：

- 不是所有失败都发生在“多桩切换”阶段
- 还有相当一部分失败发生在“第一个可达桩都没真正到达之前”

因此 go13 的重点不能只是继续鼓励多桩探索，还必须：

- **降低返航触发过晚的概率**
- **提高进入 charge 模式后的生存确定性**

---

## 3. go13 方案总览

go13 建议分两条主线同时处理，但仍只在 reward / planner 层小步修改。

### 3.1 主线一：给“更早到达第 2 / 第 3 个充电桩”提供时间敏感奖励

现有 go12 的到达奖励是：

- 到了就给
- 但不区分到得早还是晚

go13 建议改成：

- **第 1 / 第 2 / 第 3 个充电桩首次到达奖励仍保留**
- 但对第 2 / 第 3 个充电桩增加“时机因子”

核心思想：

- 第 2 个桩越早到，奖励越高
- 第 3 个桩越早到，奖励越高
- 到得很晚，奖励显著衰减

建议形式：

```python
arrival_bonus = base_bonus * time_factor
time_factor = max(floor, 1.0 - step_no / target_step)
```

建议按到达序号区分：

- 第 1 个桩：维持轻奖励
- 第 2 个桩：重点奖励
- 第 3 个桩：次重点奖励

原因：

- 第 1 个桩多数局本来就能到
- 真正拉开策略差异的是第 2 / 第 3 个桩

### 3.2 主线二：在 planner 中优先利用“已知但未到达过”的充电桩

当前 planner 的充电决策更偏向“最近可回桩”。

这会导致一个常见局部最优：

- 一旦第一个桩被使用过
- 返航就持续黏在这个桩附近

go13 建议增加一个轻量 bias：

- 若当前处于安全探索区间
- 且存在“已知但未到达过”的充电桩
- 在 coverage target / charge target 的选择中，给这些桩附近区域额外加分

这不是强制改路，而是轻量优先级提升。

目标是：

- 避免长期围绕单桩形成局部闭环
- 提高第 2 / 第 3 个桩进入可达路径的概率

---

## 4. go13 具体改动建议

### 4.1 reward 层改动

保留 go12 的“首次到达充电桩奖励”，但改成按序号和时机加权。

建议结构：

1. 第 1 个桩首次到达
   - 基础奖励较小
   - 主要用于保持基本正反馈
2. 第 2 个桩首次到达
   - 奖励最大
   - 乘早到加权
3. 第 3 个桩首次到达
   - 奖励次大
   - 同样乘早到加权

建议口径：

- 不要继续整体抬高 base bonus
- 要把奖励差异集中到“第几个桩、什么时候到”

### 4.2 planner 层改动

建议新增一个“未到达充电桩偏好”：

- 记录哪些 charger region 已经到达过
- 在 frontier / dirt 目标评分时
- 若候选区域更接近“未到达桩”，给予额外微弱 bonus

约束：

- 该 bonus 只能在非低电危险区生效
- 不得破坏当前 return safety logic
- 不得在 `charge` 模式下强行绕远

### 4.3 `charge` 模式安全修正

go13 建议对 `charge` 失败问题做小步防守性修正：

1. 小幅提前返航触发
   - 优先微调 `dynamic_return_margin`
   - 或小幅抬高 `dynamic_low_battery_ratio`
2. 在 `charge` 模式下进一步压低 residual alpha
   - 保证返回动作更接近 planner
3. 若存在多个已知充电桩
   - 返回时优先选“安全余量更大”的桩，而不只是最近桩

这一条的目标很明确：

- 先减少短局暴毙
- 再追求更好的多桩利用

---

## 5. 不建议的方向

go13 明确不建议：

1. 继续单纯加大到达奖励
   - 会提高 reward 噪声
   - 但未必改善时机
2. 用硬规则强制先走遍 3 个桩
   - 会破坏泛化
   - 容易把策略变成死板路线
3. 大改 PPO 主超参
   - 当前问题主要不在优化器
4. 同时大改 reward、planner、网络结构
   - 会再次失去归因

---

## 6. go13 建议实施顺序

推荐按下面顺序推进：

1. 先改 reward
   - 把 go12 的到达奖励改成“按序号 + 按时机加权”
2. 再改 planner
   - 给未到达过的已知充电桩增加轻量吸引
3. 最后微调 `charge` 安全边界
   - 只做小步参数修正

原因：

- 先验证多桩利用是否能更早发生
- 再看是否需要进一步提高返航保守性

---

## 7. 评估指标

go13 之后建议重点看：

- `avg_finished_steps`
- `charge` 模式失败占比
- `charger_arrived_count`
- `charger_first_arrival_step`
- `charger_second_arrival_step`
- `charger_third_arrival_step`
- `1000` 步完赛率
- `avg_score`

真正说明 go13 生效的标志是：

1. `charge` 短局失败下降
2. 第 2 个桩首次到达明显提前
3. 第 3 个桩首次到达比例上升
4. 1000 步完赛率上升
5. 分数不因过度保守而明显回落

---

## 8. go13 结论

go13 的一句话总结：

- **下一轮不再只奖励“到过新桩”，而是要奖励“更早到达第 2 / 第 3 个桩”，同时降低 `charge` 模式下的短局失败。**

这意味着 go13 的优化重点是：

- 多桩利用的时机
- 返航决策的安全性

而不是继续泛化地增加探索奖励。
