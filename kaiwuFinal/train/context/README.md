# Train Context Folder

This folder keeps the small, high-value context files that should move with the
repository and help a Linux server operator or another AI continue work without
reconstructing prior decisions.

## What Belongs Here

- session records
- migration and sync notes
- operator prompts for server-side AI
- small handoff documents with stable value

## What Does Not Belong Here

- large checkpoints
- logs
- exported docker images
- generated metric dumps
- backup archives

Keep this folder lightweight and commit-friendly.
